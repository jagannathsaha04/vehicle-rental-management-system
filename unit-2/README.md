# Unit 2: Vehicle Rental Management System (HTML, CSS & JavaScript)

Adds client-side JavaScript for interactivity, comprehensive form validation, and local data persistence.

## Features
* **Form Validation:** Validates required fields, plate format, duplicate check, and positive rental rates.
* **Dynamic Table:** Vehicles are rendered dynamically into the DOM without page reloads.
* **Add, Toggle & Delete:** Register new vehicles, toggle rental status (`AVAILABLE` ↔ `RENTED`), or remove fleet records.
* **Live Search & Filter:** Instant search by vehicle make, model, category, plate, or status.
* **Real-time KPI Statistics:** Total fleet size, available vehicles, active rentals, and average daily rate update instantly.
* **Local Storage Persistence:** Data persists in the browser's `localStorage` with a reset option.

## How to Run
Simply open `index.html` in any web browser.
