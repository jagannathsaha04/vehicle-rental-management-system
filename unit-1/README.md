# Unit 1: Vehicle Rental Management System (HTML & CSS)

A static web interface for the Vehicle Rental Management System built using pure HTML5 and modern CSS3.

## Pages
* `index.html` - Fleet dashboard with summary metric cards, status badges, and vehicle records table.
* `add-vehicle.html` - Semantic form to input and register new fleet vehicles.
* `style.css` - Responsive stylesheet for cards, tables, badges, and input forms.

## How to Run
Simply open `index.html` in any web browser (double-click the file).
